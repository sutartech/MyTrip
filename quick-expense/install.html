Keep MyTrip and install Quick Expense.

  1. Tap Open Chrome above. If Chrome does not open, copy the expense link and paste it into Chrome.
  2. On the expense form, tap Chrome ⋮ → Install and create shortcut (or Add to Home screen) → Install Quick Expense.
  3. Name it Quick Expense, check its ₹ icon, then tap Add / Add to Home screen.

Do not install MyTrip again or remove your existing app. If Chrome offers a separate Install Quick Expense prompt, you may use it instead.

A shortcut is a home-screen button, not necessarily a second app in All apps. Verify that both icons are visible on your Home screen; this website cannot inspect it.

iPhone: open the expense form in Safari → Share → Add to Home Screen.

Treat this link as an access key. Anyone holding it can use the expense permissions allowed by the Administrator. Pausing or expiring the link still blocks access.
